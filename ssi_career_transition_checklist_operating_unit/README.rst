Glue module that adds Operating Unit support to the Career Transition Checklist
module. Extends ``career_transition_checklist`` and
``career_transition_checklist.item`` with ``mixin.single_operating_unit`` so that
each checklist and its automatically loaded items are scoped to an operating unit.
