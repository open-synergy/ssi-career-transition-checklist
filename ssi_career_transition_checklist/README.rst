==============================
Career Transition Checklist
==============================

This module provides a checklist system for employee career transitions.
Supports onboarding, offboarding, and other transition-related tasks with
both automatic (Python-evaluated) and manual checklist items.

The checklist document lifecycle is: Draft → Waiting for Approval → In Progress → Done.
Transition to Done requires all checklist items to be completed.
